# Shiv Shakti RO Filter

A modern responsive landing page for a RO water purifier sales and service business based in Basti, Uttar Pradesh. The website helps customers browse RO models and pricing, view available brands, register service complaints, and contact the business quickly via phone or WhatsApp.

## Overview

This project is a static storefront website for Shiv Shakti RO Filter & Service. It is designed to promote local RO purifier products, highlight pricing, and simplify after-sales support for customers in Rudhauli and Basti.

## Features

- Hero section with service-focused branding
- RO model and pricing cards
- Brand showcase for major purifier brands
- Filter buttons for model categories
- Complaint registration form with image upload support
- WhatsApp-based complaint submission flow
- Contact details and business location section
- Mobile-friendly responsive layout

## Tech Stack

- HTML5
- Tailwind CSS
- Font Awesome Icons
- Vanilla JavaScript

## Run Locally

Because this is a static site, you can open `index.html` directly in a browser.

For a local HTTP server, run:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
